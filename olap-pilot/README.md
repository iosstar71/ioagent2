# 다차원 분석(OLAP) 파일럿

제조 실적 데이터를 차원 순서에 구애받지 않고 피벗 분석하는 파일럿입니다.
행·열에 놓은 차원의 순서를 끌어서 바꾸면 그 순서대로 서버가 다시 집계합니다.

이 디렉터리는 저장소의 다른 프로그램과 독립적입니다.

## 구성

```
[브라우저 피벗 화면]  --JSON-->  [Java 11 집계 API]  --JDBC-->  [DuckDB 파일]
                                                      운영 시 ->  [Oracle]
```

- **서버**: Java 11, JDK 내장 HTTP 서버, DuckDB JDBC, Gson
- **화면**: 외부 라이브러리 없는 HTML/JS (폐쇄망에서 그대로 동작)
- **데이터**: 첫 실행 때 가상 제조 실적 약 7만 9천 건을 DuckDB 파일로 생성

## 실행

JDK 11 이상과 Maven이 필요합니다.

```bash
./run.sh
```

Windows에서는 `run.bat`을 실행합니다. 그 뒤 브라우저에서 `http://localhost:8080`을 엽니다.
포트와 DB 파일 위치는 인자로 바꿀 수 있습니다(`./run.sh 9000 data/my.duckdb`).

테스트만 돌리려면 `mvn test`를 실행합니다.

## 화면 사용법

| 동작 | 방법 |
|---|---|
| 차원 배치 | 왼쪽 차원을 필터·열·행 영역으로 끌어 놓기 (체크하면 행 끝에 추가) |
| 순서 변경 | 놓인 칩을 끌어 원하는 위치에 놓기 |
| 차원 제외 | 칩의 × 또는 칩을 왼쪽 목록으로 끌어 놓기 |
| 값 필터 | 칩의 ▾에서 값 선택 |
| 드릴다운 | 행 머리글의 ▸ / ▾ |
| 상세 내역 | 셀 더블클릭 (최대 500건) |
| 행↔열 | 행과 열 차원을 맞바꿈 |
| 뷰 저장 | 현재 배치를 이름으로 저장 (해당 브라우저에만 저장됨) |
| SQL 보기 | 방금 실행된 집계 SQL 표시 |

## 코드 구조

| 파일 | 역할 |
|---|---|
| `pivot-meta.json` | 팩트 테이블, 차원, 측정값 정의. SQL에 들어갈 수 있는 이름의 화이트리스트 |
| `PivotQueryBuilder` | 배치를 `GROUP BY GROUPING SETS` SQL로 변환. 값은 전부 바인드 변수 |
| `PivotService` | SQL 실행 및 응답 변환 |
| `SqlDialect` | DB별 차이(현재는 행 수 제한 문법뿐) |
| `SampleData` | 가상 데이터 생성 (DuckDB 전용, 파일럿 한정) |
| `Main` | HTTP 서버와 라우팅 (파일럿 한정) |
| `web/` | 피벗 화면 |

비율 지표(수율, 불량률, 가동률)는 `SUM(분자) / SUM(분모)`로 각 집계 수준에서 다시 계산합니다.
하위 값의 평균을 내지 않으므로 소계와 총계에서도 값이 맞습니다.

## 실제 데이터로 바꾸기

1. Oracle에서 분석 단위로 요약한 데이터를 CSV로 내려받습니다.
2. DuckDB 파일에 `FACT_PROD_DAILY` 테이블로 적재합니다.
   `CREATE TABLE FACT_PROD_DAILY AS SELECT * FROM read_csv('fact.csv');`
3. 컬럼 구성이 다르면 `pivot-meta.json`의 차원과 측정값을 맞게 고칩니다.

차원 컬럼은 문자열로 다룹니다. 날짜 컬럼은 `YYYY-MM-DD` 형식의 문자열로 준비합니다.

## Oracle 전환 시 할 일

- `PivotService`에 `SqlDialect.ORACLE`과 기존 서버의 커넥션 풀을 연결합니다.
- `Main` 대신 기존 Java 서버의 컨트롤러가 `PivotService`를 호출하게 하고, 인증을 붙입니다.
- `pivot-meta.json`의 테이블·컬럼명을 Oracle의 요약 테이블(또는 Materialized View)에 맞춥니다.
- Oracle 방언은 SQL 문자열 생성만 테스트했고 실제 Oracle에서 실행해 보지는 않았습니다. 전환 시 검증이 필요합니다.

## 파일럿의 한계

- 인증과 권한이 없고 `127.0.0.1`에서만 접속됩니다.
- 값이 비어 있는(NULL) 차원 값은 필터 목록에 나오지 않습니다.
- 측정값 기준 정렬, 차트, 엑셀(xlsx) 내보내기는 없습니다.
- 집계 결과가 10만 건을 넘으면 일부만 표시합니다.
