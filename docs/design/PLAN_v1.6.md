# v1.6 계획 — Summary · Dashboard · Phase 진척 역할 정리

상태: **방향 결정 (2026-11)** — 만들기 전에 실제 화면에 입힌 전 · 후 캡처로 한 번 더 확인받는다.

## 왜
- Dashboard 는 블록 12개 · 세로 약 2,200px (샘플 기준) — 많고 겹침
  - 서브시스템 진척 카드 · 불릿 차트 · Summary 신호등이 같은 내용
  - 서브시스템별 산출물 · VOC 표가 Phase 진척 [1] 과 같음, 조회 필터가 화면 중간
- Phase 진척은 % 표 3개뿐 — 어느 단계에서 무엇이 늦는지 알 수 없음

## 역할
| 화면 | 누구 · 언제 | 담을 것 |
|---|---|---|
| **Summary** | 경영진 보고 — 판단할 것만 한 화면 | 종합 달성률 · GAP · 기준선 대비 종료 예정, 핵심 숫자 4개, 서브시스템 신호등, **주요 위험 상위 5건**(지연 · 선행 지연 · 치명 결함 · 범위 협의), 다가오는 마일스톤, 보고서 버튼. 도메인 표는 Dashboard 로 |
| **Dashboard** | PM · PL 이 매일 — 한눈에 (스크롤 1~2번) | ① 조회 필터 맨 위 ② 핵심 숫자 4개 + 체크할 일 한 줄 ③ S-curve \| 서브시스템 불릿 차트 (나란히) ④ 요약 카드 4개: 요구사항 · VOC · 테스트 결함 · 산출물 (숫자 + 막대, 누르면 해당 화면 · Phase 진척으로) |
| **Phase 진척** | 원인 찾기 — 서브시스템 × 단계 상세 | [1] 서브시스템별 진척율(유지) [2] 단계 매트릭스 + 칸마다 지연 Task 수 · 기준선 대비 +N일 (누르면 그 단계 Task 를 WBS 에서 걸러 엶) [3] 단계별 산출물 제출(단계 × 차수, 지연 표시) [4] 단계별 VOC · 테스트 결함(소진 차트 — 기준일까지 통합테스트 접수가 있을 때만) [5] 개선과제 진척(유지) |

## 빼거나 옮기는 것 (Dashboard)
- 서브시스템 진척 카드 → **삭제** (불릿 차트 유지: 비교 · 계획 대비 차이 · 서브시스템이 늘어도 높이가 조금만 늘어남)
  - 불릿 차트 상태 색 = Summary 신호등과 같은 기준(달성률 90% · 70%), 줄에 마우스를 올리면 담당 PM · Task 수
- 상태별 건수 줄 → 삭제 (체크할 일과 겹침)
- 산출물 · VOC 표, 단계별 VOC 표, 결함 차트 → Phase 진척 [3] · [4]
