G v1.0은 영어를 기본 언어로 설계하므로 미리보기 화면도 영어로 표시했습니다. 한국어 화면은 같은 구조에 언어 파일만 바뀝니다.

  • 머리글 1줄: 로고 · 프로젝트 선택 · 보고 기준일 · 검색 · 저장 상태와 [Save all] · 공지 · 사용자 메뉴(언어, 비밀번호, 잠금, 로그아웃, 도움말).
  • 탭 1줄: 원본의 탭 13개와 순서를 유지하고 업무 묶음(개요 · 일정 · 범위 · 보고 · 관리)마다 구분선과 작은 묶음 이름만 추가. 관리 묶음은 오른쪽 끝에 두고 권한이 없으면 숨김. 화면이 좁으면 탭 줄이 가로로 스크롤됩니다.
  • 화면 머리글: 화면 이름 + 그 화면의 작업 버튼(실적 반영, 내려받기 ▾, 올리기 ▾, 저장)을 한 곳에.
  • 상세 패널: WBS·요구사항·VOC에서 행을 고르면 오른쪽에 열리는 선택 기능. 표에서 바로 고치는 기존 방식은 그대로입니다.
  • 레이아웃 2종: 같은 메뉴 정의를 위쪽 탭 또는 왼쪽 메뉴로 그리는 설정. 기존 4종을 2종으로 줄여 확인할 조합이 절반으로 줄어듭니다.
3 · 기본 테마 3종

테마 색상 검토

테마는 색 변수(토큰) 값만 바꾸는 방식이라 화면 코드는 하나입니다. 상태 색(완료·진행·지연)은 테마와 관계없이 같은 의미를 유지하고, 모든 글자 색은 배경 대비 WCAG AA(4.5:1) 이상으로 맞춥니다.

Navy · 기본현재 Enterprise Navy를 정리한 색. 보고서·관공서·제조 고객에게 무난하고 로고 색과 같은 계열.head #14284F · accent #1E40AF · bg #F4F6FA
Teal · 차분한 밝은 화면장시간 입력 작업에 눈이 덜 피로한 청록 계열. 해외 SaaS 제품과 비슷한 인상이라 데모·영업용으로 적합.head #0F3D3E · accent #0F766E · bg #F3F7F7
Graphite · 어두운 화면관제실·현장 모니터, 야간 작업용. 강조색은 호박색, 마일스톤은 하늘색으로 바꿔 어두운 배경에서도 구분.head #0B0E12 · accent #F59E0B · bg #111418

사용자별 테마는 로그인 사용자 설정에 저장하고, 관리자는 기본 테마를 정할 수 있게 합니다 (현재 사용자별 언어 설정과 같은 방식). 고객사 브랜드 색이 필요하면 강조색 1개만 바꾸는 "고객 강조색" 옵션을 G v1.0 이후 추가하는 것을 권장합니다.

7 · 일정

G v1.0 개발 순서 (안)

  1. 분기 · 기반 (2주): 새 저장소 생성, 언어 파일 구조 전환(영어 기본), 디자인 토큰과 테마 3종.
  2. 절충안 B 화면 (4주): 머리글 1줄 · 묶음 탭 · 화면 머리글 · 미저장 알림 바 · 검색 · 선 아이콘 · 상세 패널.
  3. 보안 · 라이선스 (3주): PBKDF2 전환, HTTPS · 쿠키 토큰 · CSP · 감사 로그, 라이선스 파일 검증.
  4. 지역화 · 패키징 (2주): 국가별 휴일 · 날짜 형식, 영문 샘플 데이터, Windows 내장 Python 패키지, 리눅스 패키지.
  5. 문서 · 검증 (2주): 영문 매뉴얼 · EULA · 오픈소스 고지, 자동 테스트 확장(테마 3종 × 언어 2종 화면 점검), 시범 고객 배포.

총 약 13주 (1인 기준). 여러 프로젝트 지원은 화면·데이터 구조 변경 폭이 커서 G v1.1.0으로 분리하는 것을 권장합니다.
