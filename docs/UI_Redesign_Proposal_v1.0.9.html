1 · 현재 화면 진단

지금 화면에서 불편한 점

상단 영역이 3줄을 차지함

머리글(제목·기준일·저장상태·DB·사용자), 조작 줄(레이아웃·테마·전체 저장·새로고침·동기화·긴급공지·도움말·잠금), 탭 13개가 각각 한 줄씩 쌓여 1080p 화면에서 본문 시작이 약 190px 아래로 밀립니다.

탭 13개가 한 줄에 나열됨

업무 흐름(계획 → 실행 → 보고 → 관리)과 상관없이 같은 무게로 놓여 있어, 일반 사용자가 쓰지 않는 기준정보·시스템 설정도 항상 보입니다.

버튼과 아이콘이 많고 기준이 섞임

이모지 아이콘이 운영체제마다 다르게 보이고, 한 화면에 강조 버튼이 4~6개씩 있어 주 작업이 무엇인지 드러나지 않습니다.

레이아웃 4종 · 테마 다수 유지 부담

상단탭·좌측사이드바·컴팩트·업무관리 분리형 4가지 레이아웃과 테마별 CSS 덮어쓰기가 겹쳐, 새 화면을 만들 때마다 모든 조합을 확인해야 합니다.

4 · 디자인 기준

색 · 글꼴 · 아이콘 · 버튼

디자인 토큰

색·글꼴 크기·간격·모서리를 --color-*, --space-* 같은 CSS 변수로만 지정합니다. 밝은/어두운 화면과 강조색 프리셋(네이비·틸·그린 등 현재 테마 이름 유지)은 변수 값만 바꿔 적용하므로 테마별 CSS 덮어쓰기가 사라집니다.

글꼴

Pretendard(SIL OFL 1.1)를 woff2로 프로그램 폴더에 포함하고, 없으면 맑은 고딕으로 표시합니다. 숫자 열은 고정폭 숫자(tabular-nums)로 정렬합니다.

아이콘

이모지 대신 선 아이콘 1종(Lucide, ISC 라이선스)을 SVG 스프라이트 1개 파일로 포함합니다. 운영체제와 관계없이 같은 모양으로 보이고, 실제 쓰는 아이콘 40~60개만 넣어 약 30KB입니다.

버튼 규칙

영역마다 주 버튼은 1개(채움), 나머지는 보조(테두리)·텍스트 버튼. 위험 작업(삭제·초기화)은 빨간 글자 + 확인 대화상자. v1.0.7의 data-btn 분류를 그대로 이어서 색만 토큰으로 바꿉니다.

6 · 구현 방식

단계별 적용 계획

한 번에 바꾸지 않고, 새 셸을 <body data-ui="v2"> 설정으로 켜고 끌 수 있게 만들어 기존 화면을 대체 경로로 남겨 둡니다. 각 단계는 자동 테스트(API 10건 · E2E 32건)를 통과해야 다음 단계로 넘어갑니다.

1단계 · 2주
토큰 · 버튼 · 아이콘
style.css 맨 앞에 토큰 계층을 추가하고 CSS 계층(@layer tokens, base, components, screens, legacy)으로 정리. 이모지 → SVG 아이콘 교체. 화면 구조는 그대로.
2단계 · 3주
앱 셸
좌측 메뉴 · 상단 바 · 화면 머리글 · 미저장 알림 바 · Ctrl+K 검색. 기존 activateTab()과 권한별 메뉴 숨김(installTabGuards)을 그대로 재사용.
3단계 · 4주
화면 개편
주간보고 2단 구성, WBS 상세 패널, 대시보드 "확인할 일", 설정 화면 보조 메뉴 순서로 적용.
4단계 · 1주
정리
사용하지 않게 된 레이아웃 3종과 테마별 덮어쓰기 CSS 제거, 매뉴얼 화면 캡처 갱신.

지원 브라우저: 사내 표준 Chrome·Edge(Chromium 105 이상). CSS 변수, @layer, :has(), 컨테이너 쿼리를 사용하며 Internet Explorer는 현재와 같이 지원하지 않습니다.

7 · 보안

보안 검토

항목방안
외부 통신글꼴·아이콘·스크립트를 모두 프로그램 폴더에 포함. CDN·웹폰트 서버 호출 없음 (폐쇄망 그대로 동작).
스크립트 실행 제한 (CSP)HTML 안의 onclick= 인라인 처리기를 단계적으로 addEventListener로 옮긴 뒤, DB 서버 모드에서 Content-Security-Policy: script-src 'self'; frame-ancestors 'none' 헤더를 보냄. Standalone.html은 구조상 인라인 스크립트가 필요하므로 대상에서 제외.
화면 출력사용자 입력은 지금처럼 escapeHtml()을 거쳐 출력하고, 새 컴포넌트는 textContent 기반으로 작성. 검색 결과 강조도 문자열 결합 대신 DOM 노드로 생성.
브라우저 저장소메뉴 접힘·화면 밀도 같은 화면 설정만 localStorage에 저장. 토큰·비밀번호 해시는 저장하지 않음 (현재 규칙 유지).
권한별 메뉴메뉴 숨김은 편의 기능이며, 실제 권한 검사는 지금처럼 서버(wbs_db_server.py)에서 다시 확인.
