   - 자료는 각자 PC 브라우저(IndexedDB "pprjmgmt")에 저장, 사람 사이는 "파일"로 주고받음

■ 배포 폴더 (pprjmgmt/, 풀었을 때 약 2.6MB)
  index.html          시작 파일 (폴더 맨 위)
  static/             화면 파일 (js · css · 글꼴)
  legal/              오픈소스 고지 (Pretendard 글꼴)
  shared/             PM 이 넣는 최신 종합본 자리 (latest.json) — 작업자 화면이 열릴 때 자동으로 읽음
  README.txt          이 문서

■ 설치
  1) pprjmgmt_v1.0.0_local.zip 을 풀어 나온 pprjmgmt 폴더를 전사 웹 서버의 /pprjmgmt 위치에 그대로 복사
  2) https://xxx.com/pprjmgmt/ 접속 — 끝 (서버 설정 · 포트 · DB 없음)
  3) 처음 작업자: admin / admin123! (처음 고를 때 새 암호로 바꿔야 함). 프로젝트 정보는 비어 있음
  * 외부 주소로 나가는 요청 없음 (CSP 로 막음). 전사 시스템의 localStorage 는 건드리지 않음
  * shared/latest.json 은 사내망에서 주소를 아는 사람은 누구나 내려받을 수 있음 (작업자 선택 로그인과 무관)

■ 작업자 선택 (로그인이 아님)
  - 전사 SSO 와 별개로, 이 프로그램 안에서 일하는 "작업자"를 고르는 화면
  - ① 프로젝트 → ② 작업자 → ③ 작업자 암호 → [▶ 작업 시작]
  - 초기 암호 = 작업자 ID + 123!  (예: hong → hong123!) — 작업자를 추가하거나 암호를 초기화하면 이 값
    처음 고를 때 새 암호(8자 이상, 영문 + 숫자, 초기 암호와 달라야 함)로 바꿈
  - 자료가 PC 마다 따로 있으므로 작업자 목록도 PC 마다 따로 있음 → PM 의 종합본 파일로 맞춤

■ 함께 일하는 방법 (파일 주고받기)
  [PM]
   1) 프로젝트 · 서브시스템 · 작업자(담당 서브시스템)를 등록
   2) 최신 종합본 배포 — 둘 중 하나
      (가) 권장: [🔀 스마트 병합 > 📦 종합본 > 🌐 배포용 latest.json] → 받은 파일을 배포 폴더 pprjmgmt/shared/ 에 넣고
              pprjmgmt 폴더 전체를 올림 (이전 판은 shared/history/ 에 옮겨 두면 기록이 남음)
              → 작업자가 화면을 열면 자동으로 읽음: 자료가 없는 PC 는 그것으로 시작, 자료가 있는 PC 는
                새 버전일 때 작업자를 고르면 반영 (내 담당 서브시스템은 그 PC 작업 유지). 같은 버전은 다시 안 함
              → PM · 관리자 PC 는 자기가 만든 버전이라 그대로. 다른 PC 의 PM 은 반영 전에 한 번 물어봄
      (나) 📥 JSON (전체) 내려받기 → 메일 · 메신저 · 공유 폴더로 작업자에게 전달
      (종합본에는 버전 표시와 작업자 목록이 들어 있음, 작업자 암호는 없음)
  [작업자]
   3) (가) 방식이면 화면만 열면 됨. (나) 방식이면 작업자 선택 화면의 [📥 PM 이 보낸 종합본 올리기 (최신 자료 받기)] → 받은 파일 선택
      - 이 PC 에 그 프로젝트 자료가 없으면: 종합본으로 바로 시작
      - 있으면 고르기 (종합본 버전과 이 PC 버전을 비교해 새것 / 같음 / 오래됨 표시)
          🔄 최신 종합본으로 맞추기 (권장): 작업자를 고르면 반영 — 내 담당 서브시스템은 이 PC 작업 유지, 나머지는 종합본대로
          이 PC 자료 그대로 쓰기
          ♻️ 종합본으로 전부 바꾸기: 한 번 더 확인 후 이 PC 자료를 버리고 종합본과 똑같이
   4) 자기 서브시스템 작업 후 [🔀 스마트 병합]에서 내 자료(JSON) 내려받기 → PM 에게 전달
      (어느 종합본을 받아 작업했는지가 파일에 표시됨)
   5) 새 종합본을 받으면 3) 처럼 작업자 선택 화면에서 올리거나, 작업 중에는 [🔀 스마트 병합 > 종합본 가져오기]
  [PM]
   6) 받은 파일을 [🔀 스마트 병합]에 올려 미리보기 확인 후 합침
      - 이전 종합본을 받아 작업한 파일이면 미리보기에 ⚠️ 경고 (보낸 사람 표시)
   7) 다시 종합본을 내려받아 배포 (2)로)
  * 서브시스템 하나는 한 사람이 맡는 것을 원칙으로 함 (같은 서브시스템을 둘이 고치면 나중에 합친 쪽이 이김)

■ 저장 · 백업 (중요)
  - 자료는 그 PC · 그 브라우저에만 있음. 다른 PC · 다른 브라우저 · 브라우저 자료 삭제 시 볼 수 없음
  - 파일로 저장한 지 7일이 지나면 작업 시작 때 백업 알림
  - [💾 백업 · 복원]: 프로젝트(엑셀 / JSON), 시스템 전체(JSON) 내려받기 · 복원
  - [시스템 설정 > 🗄️ 데이터 관리]: 이 브라우저 저장 용량 · 초기화(관리자만, 프로젝트 이름 입력 확인)
