PM Hub — IOSTAR-PM Standalone v1.0.0
   - 브랜드: IOSTAR-PM · 판: Standalone (DB · 서버 없음) / Workgroup (서버 DB) / Enterprise (전사)
   - 사내 표시 이름: PM Hub · 주소: https://xxx.com/pprjmgmt/
   - html · css · js 파일만 (정적 호스팅에 폴더째 올리면 끝, 서버 프로그램 없음)
   - 자료는 각자 PC 브라우저(IndexedDB "pprjmgmt")에 저장, 사람 사이는 파일로 주고받음
   - 화면 언어: 한국어 / English (멤버 선택 화면에서 고름, 멤버마다 기억)
   - 브랜치: iostar-pm-standalone

■ 배포 파일
  IOSTAR-PM-Standalone_v1.0.0.zip → 풀면 pprjmgmt/ 폴더 하나 (폴더 이름 = 웹 주소 /pprjmgmt)
    index.html   시작 파일          static/   화면 파일 (js · css · 글꼴)
    shared/      PM 이 넣는 최신 마스터 파일 자리 (latest.json)
    legal/       오픈소스 고지       README.txt  이 문서

■ 설치
  1) zip 을 풀어 나온 pprjmgmt 폴더를 전사 웹 서버의 /pprjmgmt 위치에 그대로 복사
  2) https://xxx.com/pprjmgmt/ 접속 — 처음 멤버: admin / admin123! (바꾸지 않고 써도 됨)
  * 폴더 안 index.html 을 PC 에서 바로 열어도 동작 (이때 shared/latest.json 자동 받기는 쓰지 않음)
  * 외부 주소로 나가는 요청 없음. 전사 시스템의 localStorage 는 건드리지 않음
  * shared/latest.json 은 사내망에서 주소를 아는 사람은 누구나 다운로드할 수 있음

■ 업그레이드 · 초기화
  - 새 버전: zip 을 풀어 pprjmgmt 폴더를 덮어쓰면 끝. 자료(브라우저 저장소)는 그대로이고 암호도 그대로
    → 화면을 열면 "새 버전으로 바뀌었습니다" 를 한 번 알림
  - 처음 상태로: 관리자로 [Admin > 🗄️ 데이터 관리 > 완전 초기화], 또는 브라우저의 이 사이트 데이터 삭제
    (그 PC · 그 브라우저의 자료만 지워짐. 먼저 [💾 백업 · 복원]에서 백업 권장)
  - 암호만 처음으로: 관리자 · PM 이 [프로젝트 설정 > 멤버 정보]에서 [🔄 초기화] → 멤버 ID + 123!

■ 메뉴
  🙋 My Work      내 체크할 일(지연 · 마감 임박 · 미조치 VOC · 산출물 · Action Item) + 내 담당 Task + 내 할 일
  📊 Dashboard    Summary(한 화면 요약) · Dashboard(그래프 · 통계) · Phase 진척
  🗓️ 일정         WBS · Gantt
  🎯 요구 · VOC · 산출물   요구사항(REQ) · VOC · 이슈(구분: VOC / 버그 / 이슈) · 산출물
  🤝 보고 · 소통   주간보고 · 회의 · 게시판(공지 · 게시판)
  ⚙ 관리          프로젝트 설정 · 파일 Merge · Admin
  - 로그인 후 첫 화면: 관리자 · PM · PL = Summary, 멤버 = My Work ([Admin > 화면 · 테마 > 역할별 첫 화면])

■ 화면 · 테마
  - 테마 5가지 (머리말 [화면] 또는 [프로젝트 설정]의 테마, 프로젝트마다 기억)
    Urban Slate(기본, 밝은 회청색) · Electric(선명한 청보라) · Nordic Sage(밝은 세이지) · Brown(따뜻한 무광 브라운) · Obsidian(어두운 화면)
    예전 테마는 자동으로 가까운 테마로: Navy · Matte → Urban Slate, Green → Nordic Sage, Graphite → Obsidian
  - 로고: 밝은 머리말 테마(Urban Slate · Nordic Sage · Brown)는 무채색 로고, 나머지는 색 로고 (브라우저 탭 아이콘도 같이)
  - 아이콘: 화면의 그림 문자는 모두 같은 모양의 선 아이콘으로 그림 (상태 아이콘만 테마의 정상 · 주의 · 위험 색)
  - 차트(S-curve · 불릿 차트 · 대시보드 표 색)도 테마 색을 따름. 엑셀 · 워드 · PPT 보고서 색은 [보고서 테마] 설정을 따름
  - 기본 테마는 conf/app.ini [ui] default_theme (urban-slate)

■ 멤버 선택 (로그인이 아님)
  - 전사 SSO 와 별개로, 이 프로그램에서 일하는 멤버를 고르는 화면
  - 처음 암호 = 멤버 ID + 123! (예: hong → hong123!). 바꾸지 않아도 됨. 바꾸려면 [🔑 암호 변경]
  - 역할: 관리자 · PM · PL(담당 서브시스템, ALL 이면 전체) · 멤버(담당 서브시스템만 저장)

■ 함께 일하는 방법 (파일 주고받기) — 화면 위쪽 노란 [📦 마스터 파일 ▾] 에 모여 있음
  [PM]
   1) 프로젝트 · 서브시스템 · 멤버(담당 서브시스템)를 등록
   2) 최신 마스터 파일 배포 — 둘 중 하나
      (가) [🌐 배포용 latest.json 다운로드] → 배포 폴더 pprjmgmt/shared/ 에 넣고 폴더 전체를 올림
           → 멤버가 화면을 열면 자동으로 받음 (자료 없는 PC 는 그것으로 시작, 있는 PC 는 새 버전일 때
             멤버를 고르면 반영 · 내 담당 서브시스템은 그 PC 작업 유지)
      (나) [📥 마스터 파일 다운로드 (JSON)] → 메일 · 메신저 · 공유 폴더로 전달
  [멤버]
   3) (나) 방식이면 멤버 선택 화면의 [📥 PM 이 보낸 마스터 파일 업로드] → 최신으로 맞추기 / 그대로 / 전부 바꾸기
   4) 내 담당 작업 후 [📤 내 작업 파일 다운로드 (엑셀 / JSON)] → PM 에게 전달
      (어느 마스터 파일 기준인지 · 보낸 사람이 파일에 들어감)
  [PM]
   5) [📋 멤버 자료 받아 합치기] → 미리 보기 확인 후 반영 (이전 마스터 파일 기준이면 ⚠️ 경고)
   6) 다시 2) 로
  * 서브시스템 하나는 한 사람이 맡는 것이 원칙 (같은 서브시스템을 둘이 고치면 나중에 합친 쪽이 이김)

■ WBS 규칙
  - 가중치: 서브시스템마다 L1 합 100, 상위 = 하위 합 (소수점 1자리). 상위를 바꾸면 하위가 같은 비율로 따라감
  - 오류(가중치 · 휴일 · 날짜 역전 · 기간 이탈)는 같은 색 칸 + "⚠️ 오류" 건수로 표시 → [⚖️ 가중치 맞추기] ·
    [🗓️ 휴일 날짜 옮기기] 로 고침. 프로젝트 종합 = 서브시스템 진척률 × 서브시스템 가중치
  - 상태: 완료 / 지연(계획보다 판정 차이 이상 적거나 계획종료일 경과 미완료) / 진행중 / 대기
    판정 차이(기본 5%p) · 마감 임박(기본 7일): [프로젝트 설정 > 휴일정보 > 🚦 판정 기준]
  - [⚡ 계획 → 실적 채우기]: 계획 진척률이 있는 최하위 Task 모두, 기준일이 속한 주차 기준
    실제 시작 = 계획시작이 주차보다 앞이면 주차 시작일, 주차 안이면 계획시작일
    실제 종료(100%) = 계획종료가 주차 안이면 계획종료일, 앞이면 기준일 (이미 입력된 실적일은 그대로)
  - 📶 단계별 조회: WBS 조회 맨 앞에서 단계(Phase)를 고르면 그 단계 Task 와 상위 Task 만 표시
  - 주간보고 금주 Task: 계획 기간이 금주에 걸친 Task · 지연 Task · 실적 진행 중 · 금주 완료
    오래 밀린 Task 는 항상 금주에 '지연' 으로 (계획종료일 · 경과 일수 표시)

■ 저장 · 백업 (중요)
  - 자료는 그 PC · 그 브라우저에만 있음. 다른 PC · 브라우저 · 브라우저 자료 삭제 시 볼 수 없음
  - 파일로 저장한 지 7일이 지나면 작업 시작 때 백업 알림
  - [💾 백업 · 복원]: 프로젝트(엑셀 / JSON), 시스템 전체(JSON) 다운로드 · 복원, 스냅샷
  - 🧪 샘플 프로젝트: [Admin > 🗂️ 프로젝트 > 🧪 샘플 프로젝트 추가] (교육 · 시연용, 새 프로젝트로 추가)

■ Workgroup(서버 판)과의 관계
  - 같은 화면 · 같은 자료 형식. Standalone 의 프로젝트 백업(JSON)을 Workgroup 에 올리면 새 프로젝트로,
    Workgroup 의 프로젝트 백업을 Standalone 에 올려도 같은 방식으로 들어감 (팀이 서버로 옮길 때 · 서버 장애 때)
  - Workgroup 에만 있는 기능: 서버 DB 공유, 서브시스템 체크아웃 · 체크인, 채팅

■ 개발용 (배포 묶음에는 없음)
  conf/app.ini                  브랜드 · 사내 표시 이름 · 판 · 버전 · 하위 주소(base_path)
  data/initial_data.json        처음 상태(admin 하나) 원본
  python tools/make_release.py <출력폴더>   배포 zip (5MB 넘으면 중단)
  node tools/tests/e2e/run_e2e.js           브라우저 시험 (zip 을 풀어 /pprjmgmt 아래 정적 서버로 시험)
