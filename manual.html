1. 시작하기

  1. 브라우저(Edge · Chrome)에서 안내받은 주소(또는 받은 폴더의 index.html)를 엽니다.
  2. 프로젝트와 멤버를 고르고 암호를 넣어 [작업 시작]. 처음 암호는 1234 이고, 처음 들어올 때 새 암호로 바꿔야 합니다.
  3. Standalone 은 서버가 없습니다. 자료는 이 PC 의 브라우저에 저장되고, 다른 사람과는 마스터 파일(PM 이 나눠 주는 전체 자료)과 내 작업 파일(멤버가 PM 에게 보내는 자료)로 주고받습니다.
  4. 처음 쓰는 PC 라면 PM 이 준 마스터 파일을 맨 위 [📦 마스터 파일 ▾ > 가져오기]로 넣고 시작합니다.
  5. 서버(http 주소)로 열었고 배포 폴더에 마스터 파일이 있으면, 처음 열 때 그 파일로 시작할지 묻습니다. 내 PC 의 index.html 로 연 것과 http 주소로 연 것은 서로 다른 저장소라 자료가 섞이지 않습니다.

3. 저장 · 새로고침 · 파일 주고받기

  • 저장: 고친 내용은 [저장](화면별) 또는 [전체 저장](Ctrl+S)을 눌러야 이 PC 에 기록됩니다. 작성 중인 주간보고 · 회의록도 함께 저장됩니다. 기준일 · 테마 같은 화면 설정은 바로 기록됩니다.
  • 새로고침: 마지막으로 저장한 상태로 되돌립니다. 화면에서 고른 조건(필터 · 검색어)은 그대로 둡니다. 저장하지 않은 변경이 있으면 먼저 물어봅니다.
  • 화면을 닫을 때 저장하지 않은 변경이 있으면 브라우저가 한 번 더 묻습니다.
  • 멤버: 내 담당 서브시스템을 고친 뒤 [📦 마스터 파일 ▾ > 내 작업 파일 보내기]로 파일을 받아 PM 에게 전달합니다.
  • PM: 받은 파일을 [파일 Merge]에서 업로드 → 미리 보기 확인 → 반영하고, 새 마스터 파일을 내려받아 나눠 줍니다.
  • 브라우저 자료를 지우면 저장된 내용도 사라집니다. 주기적으로 마스터 파일이나 백업을 받아 두세요.

4. 메뉴별 사용법

My Work

내가 체크할 일(지연 · 이번 주 마감 · 내 Action Item 등)과 내 담당 Task 를 봅니다. 항목을 누르면 해당 화면으로 갑니다.

Dashboard (Summary · Dashboard · Phase 진척)

  • Summary: 전체 계획 대비 실적(종합 = 서브시스템별 진척률 × 서브시스템 가중치), 서브시스템별 달성률 · 가중치, 보고서(종합보고서 PPT · 주간보고 워드) 내려받기.
  • Dashboard: S-커브, 서브시스템별 계획 대비 실적, 요구사항 · VOC · 산출물 현황.
  • Phase 진척: [1] 서브시스템별 진척율(WBS · 요구사항 · VOC · 산출물)과 단계별 계획 / 실적 / 달성률. 아직 계획 전인 칸은 "-" 로 나오고 합계에서 빠집니다.

일정 (WBS · Gantt)

  • WBS: Task 를 계층으로 나누고 일정 · 담당자 · 실적을 입력합니다. 행 끝 버튼이나 행의 빈 곳을 누르면 오른쪽 상세 패널이 열립니다.
  • 상태 버튼(전체 · 지연 · 진행중 · 대기 · 완료 · ⛓ 선행 지연)과 단계 · 도메인 · 서브시스템 · 레벨로 걸러 봅니다. 상태 버튼을 고르면 그 Task 의 상위 Task 가 레벨 보기에서 고른 레벨까지 묶음 머리로 함께 보이고, 머리마다 "지연 3건" 처럼 그 아래 건수가 붙습니다.
  • 선행 Task: 상세 패널에서 먼저 끝나야 하는 Task 를 최대 3개 지정합니다(선택). 선행이 지연되거나, 선행 계획 종료가 이 Task 계획 시작과 겹치거나, 선행이 끝나기 전에 시작하면 작업명 앞 ⛓ 이 주황색이 되고 체크할 일에 '선행 지연 영향' 으로 나옵니다. 일정을 자동으로 밀지는 않습니다. 돌고 도는 연결(A 의 선행이 B, B 의 선행이 A)은 지정할 수 없습니다.
  • Gantt: 일정 막대와 마일스톤을 봅니다.

요구 · VOC · 결함 · 산출물

목록에서 바로 고치거나 행을 눌러 오른쪽 패널에서 고칩니다. 산출물은 차수별로 계획일 · 제출일 · 상태를 관리합니다.

  • VOC · 결함: 접수하면 단계(요건분석/설계 · 구현/단위테스트 · 통합테스트 · 안정화)가 접수일로 자동으로 정해집니다. PL 은 분석 뒤 판정(결함 · 개선 요청 · 설명 종결 · 이슈)을 고릅니다. 결함이면 심각도를 적습니다.
  • 큰 개선 요청은 오른쪽 패널의 [➕ 추가 요구사항으로 등록] — 요구사항 목록에 "추가"(ID 예: CR-MES-01)로 생기고 VOC 는 "요구 반영" 이 됩니다. 작은 개선은 VOC 안에서 조치 · 완료합니다.
  • 테스트 결함 현황(대시보드 · Summary · 보고서)은 통합테스트 단계에 접수가 생기면 나타납니다. 안정화 단계 접수는 VOC 현황에만 셉니다.
  • 기준선(PM): Admin > 프로젝트 > [📐 기준선 확정]. 이후 Gantt 의 회색 선 · WBS 상세 패널 · Summary 에서 "기준선 대비 +N일" 을 봅니다. 다시 확정할 때는 사유를 적습니다.

보고 · 소통

  • 보고 > 주간보고 작성 · 출력: 주차와 작성 단위를 고르면 WBS 실적으로 초안이 만들어집니다. 고친 뒤 [작성 완료(저장)]. 목록은 기준일의 주차부터 보입니다. 다른 사람이 고쳐 저장하면 작성자도 그 사람으로 바뀝니다.
  • 보고 > 종합보고서 출력: 주차를 고르고 PPT 를 내려받습니다.
  • 보고 > 보고서 설정 (PM 이상): 엑셀 · 워드 색상(Navy · Gray · Mint), 글꼴, 파일 약칭, 종합보고서 구성(요약형 · 종합형 · 상세형 · 직접 선택)과 디자인 5종.
  • 회의: 회의일정(캘린더 + 회의 목록, 상태 버튼으로 함께 걸러짐) / 회의록 작성 · 상세 / Action Item 현황. Action Item 은 회의록에서 추가하고, 현황 목록에서 행을 눌러 고칩니다.
  • 게시판: 공지, 채널별 게시판(채널 필터 오른쪽에서 보기 방식 선택).

프로젝트 설정 (PM 이상)

  • 프로젝트 기본정보: 프로젝트 이름 · 기간 · 주 시작 요일, 도메인 · 서브시스템, 마일스톤, 표기 규칙(ID 접두사 · 주차 표시).
  • 프로젝트 부가정보: 휴일, 진척률 계산 기준, 지연 판정 기준.
  • 서브시스템: 도메인 등록, 서브시스템 목록(관리 유형 · SDLC 유형 · 가중치 · 담당 PM). 아래 [공정 유형]에서 시스템 설정의 모든 유형을 골라 단계 가중치 · 계획 일정을 정합니다 (유형 단위 저장). 목록의 ⚠ 일정 미지정을 누르면 그 유형으로 바로 이동합니다.
  • 산출물: 제출 차수, 단계별 표준 산출물, 차수별 제출일 일괄 변경.
  • 프로젝트 부가정보: 진척률 산정 기준 · 판정 기준 · 표기 규칙(ID · 주차) · 공휴일 (2열 배치).
  • 멤버 정보 · 화면 · 테마 · 게시판 채널. 보고서 설정은 [보고] 메뉴에 있습니다.

파일 Merge

  1. 범위(도메인 · 서브시스템)를 고릅니다.
  2. 자료 묶음 [작업데이터] / [기준정보 · 공지] / [마스터 파일(전체)] 을 누르거나 표에서 직접 체크합니다.
  3. [엑셀 다운로드] · [JSON 다운로드] · [파일 업로드]. 업로드는 미리 보기에서 확인한 뒤 반영됩니다.

Admin (관리자)

프로젝트 탭에서 시스템 타이틀과 프로젝트 등록 · 이름 변경 · 사용 중지 · 삭제(프로젝트와 자료 전부)를 합니다. 데이터 관리 탭에서도 프로젝트 초기화 · 삭제를 할 수 있습니다. 그 밖에 전체 멤버, SDLC 유형, 보안 · 인증, 저장소 탭이 있습니다.

v1.1.0 — 최초 기록 버전

  • 저장 방식: 자동저장을 없앴습니다. [저장] 또는 [전체 저장](Ctrl+S)을 눌러야 기록되고, [전체 새로고침]은 마지막으로 저장한 상태로 되돌립니다 (고른 조건은 유지). 화면을 닫을 때 저장하지 않은 변경이 있으면 묻습니다. 기준일 · 테마 같은 화면 설정은 묻지 않고 바로 기록됩니다.
  • 화면 표준: 서브메뉴를 화면 이름 줄 아래 한 줄로 통일 (회의 · 보고 · 게시판 · 설정)
  • 테마 6종: Slate(기본) · Walnut · Navy(새, Walnut 과 같은 틀의 블루) · Classic(예전 IT 시스템 스타일, 색 아이콘) · Obsidian · Pop
  • 맨 위 줄: [전체 새로고침] 버튼, 화면 · 관리 아이콘 변경, 멤버는 이름만 표시(메뉴에 이름 — 권한), 좁은 화면에서 넘치지 않게 정리
  • 보고 메뉴: 주간보고 작성 · 출력 / 종합보고서 출력 / 보고서 설정(PM 이상), 종합보고서 구성(요약형 · 종합형 · 상세형 · 직접 선택)과 디자인 5종, 엑셀 · 워드 색상 Navy · Gray · Mint
  • Admin: 시스템 타이틀, 프로젝트 등록 · 삭제를 탭 안에서 (예전 팝업 창 없앰)
  • Import · Export: 자료 묶음(작업데이터 / 기준정보 · 공지 / 마스터 파일), 버튼 통일. 머리글의 [마스터 파일] 메뉴는 그대로
  • 회의: 상태 버튼 필터(캘린더 + 회의 목록), Action Item 은 회의록에서 추가 · 목록에서 수정

  • 달성률: 계획 전 항목은 "-" 표시 · 합계 제외
  • 프로젝트 설정: 프로젝트 부가정보(예전 휴일정보), Phase · 산출물, 차수별 산출물 제출일 일괄 변경, 표기 규칙(ID · 주차)
  • 상세 패널: WBS · 요구사항 · VOC · 산출물 · Action Item 의 오른쪽 패널이 화면 이름 줄 아래에서 시작
  • 암호: 처음 암호를 1234 로 통일하고, 처음 들어올 때 반드시 바꾸도록 했습니다 (Workgroup 과 같음)
