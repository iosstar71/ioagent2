1. 시스템 개요 및 아키텍처 비전 (Executive Architecture Vision)

본 시스템은 제조 및 대규모 IT 프로젝트 환경에서 WBS 공정표(L1~L4), 산출물 검수(1~4회차), 요구사항(REQ), 현장 VOC·이슈, 주간보고서, 그리고 신규 추가된 회의 일정·회의록·Action Item을 단일 플랫폼에서 끊김 없이 통합 관리하도록 설계되었습니다.

🌟 4대 핵심 아키텍처 설계 원칙:
  • Zero-Dependency Client-Side Execution: 외부 Node/npm 패키지나 무거운 백엔드 프레임워크 의존 없이 표준 모던 브라우저에서 100% 독립 실행되는 반응형 SPA 구조.
  • Single Source of Truth (SSOT): 전사 WBS 공정 데이터와 기준정보(Baseline)가 대시보드, 간트차트, 진척률 매트릭스, 주간보고서, 회의록에 실시간 양방향 롤업 연동.
  • Native OpenXML Generator: 브라우저 메모리상에서 순수 JavaScript CRC32 및 ZIP 압축 바이트스트림을 구성하여 Microsoft Word(.docx) 및 Excel(.xlsx) 표준 포맷 직접 생성.
  • Multi-Channel Resilient Storage: 인메모리 반응형 상태 + LocalStorage 암호화 캐시 + File System Access API + Cross-Tab 브로드캐스트 + Python SQLite 백엔드의 5중 내구성 보장.

2. 4계층 소프트웨어 아키텍처 (4-Tier Layered Architecture)

4. 데이터 모델 & 통합 ERD (Data Entity Specifications)

시스템의 모든 엔티티는 JSON 직렬화가 가능한 자바스크립트 객체 구조로 관리되며, 엔티티 간 식별자(ID) 기반의 느슨한 결합(Loose Coupling)을 형성합니다.

🏛️ ProjectConfig Root Master
PK systemTitle, projectName
Date projectStartDate ~ projectEndDate
Date reportDate (공정 기준일)
Int maxDeliverableRounds (1~4회차)
List domains[], holidays[]
1 : N ➔
🏢 SubsystemsMeta Subsystem
PK code, name
Enum type (SDLC | REQ)
FK sdlcCode (표준 매핑)
Num weight (%) (가중치)
Str pm, domain, desc
1 : N ➔
📋 WbsData WBS (L1~L4)
PK id (계층 채번, 예: 1.1.2.1)
FK system, reqId
Num level (1~4), weight (%)
Date pStart~pEnd, aStart~aEnd
Prog pProg (계획%), aProg (실적%)
Bool isLeaf (말단 과업 여부)
🎯 ReqMasterData Requirements
PK id (예: REQ-W1-01)
FK system (서브시스템)
Str name, type, priority
Enum status (착수전|진행|완료)
💬 VocData Site VOC
PK id (예: VOC-01)
FK system (서브시스템)
Enum priority, status (대기|진행|완료)
Date reqDate, targetDate
Str title, action
📑 DeliverablesData Deliverables
PK id (순번)
FK system, phase
Str round (1~maxR회차)
Date pDate, aDate
Enum status (작성전|작성중|검토|보완완료)
📅 MeetingsData Meetings (ver1.2.0)
PK id (예: MTG-20270528-01)
FK system (서브시스템 / ALL)
Date date, startTime, endTime
List attendees[], agendas[]
List actionItems[] (1:N 연계)
📝 WeeklyReportsData Weekly Reports
PK id, weekNo, weekLabel
Date startDate ~ endDate
List currentWeekTasks[]
List nextWeekTasks[]
Text currentWeekSummary, nextWeekSummary

주요 엔티티 스키마 상세:

  • Meeting Entity: { id, system, title, date, startTime, endTime, location, host, status, attendees: [...], agendas: [...], actionItems: [...] }
  • Agenda Entity: { id, order, title, discussion, decision }
  • ActionItem Entity: { id, meetingId, title, content, requester, assignee, system, meetingDate, targetDate, status }
  • WbsData Entity: { id, level, system, name, weight, reqId, pStart, pEnd, aStart, aEnd, pProg, aProg, output, isLeaf }
  • DeliverablesData: { id, round, system, phase, name, pDate, aDate, status, manager, remarks }

크로스탭 브로드캐스트 채널 리스너 활성화. 핑퐁 무한 루프 차단 가드 대기
🛡️ 크로스탭 동기화 무한 핑퐁 루프 방지 아키텍처:
다중 브라우저 탭 실행 시 BroadcastChannel("WBS_SYNC_CHANNEL") 수신부는 상대방 탭에서 발송한 틱을 받아 데이터를 로드하기만 하며, 절대로 저장 함수(saveAll)나 브로드캐스트 틱을 역전송하지 않도록 플래그 가드를 적용하여 CPU 과점유와 무한 저장을 원천 차단했습니다.

6. 순수 JS OpenXML 변환 엔진 (Pure Client-side DOCX/XLSX Engine)

외부 서버 렌더러나 상용 라이브러리(Office SDK 등) 없이 클라이언트 브라우저에서 표준 OpenXML 패키지를 직접 생성합니다.

출력 형식 엔진 모듈 구현 방식 및 표준 준수 명세
Word (.docx) DocxBuilder WordprocessingML 규격 준수. [Content_Types].xml, styles.xml, document.xml 구성. 표 형식 모드와 완전 서술형(표 없음) 2대 모드 지원.
Excel (.xlsx) ExcelSync SpreadsheetML 규격 준수. 다중 시트(Worksheets), 셀 스타일 팔레트, 컬럼 너비 메타데이터를 직접 바이트 직렬화하여 생성.
ZIP 바이너리 ExcelSync._createZipBlob 표준 PKZIP 스펙(0x04034b50, 0x02014b50, 0x06054b50)을 순수 JS 버퍼와 DataView로 직렬화하여 무압축 OpenXML 컨테이너 생성.

7. 회의록 & Action Item 아키텍처 (Meeting Management Subsystem)

ver1.2.0의 핵심 신규 모듈인 MeetingManager는 회의 일정 관리, 회의록 작성, Action Item 추적을 상호 유기적으로 연동합니다.

📅 1단계. 회의 일정 등록
• 일자, 시작/종료 시각, 장소, 주관자 입력
• 서브시스템 매핑 (특정 서브시스템 / ALL 공통)
• 회의 상태 지정 (예정 / 진행중 / 완료 / 취소)
➔
🗓️ 2단계. 월별 캘린더 표출
• 월별 7컬럼 인터랙티브 캘린더 자동 렌더링
• 시스템 설정 휴일(법정공휴일/사용자휴일) 전면 표출
• 서브시스템별 필터 연동 및 컬러 알약(Pill) 배지
➔
📝 3단계. 회의록 작성·상세
• 서브시스템 필터 연동 회의 선택 드롭다운
• 참석자 명단 및 직책/출석 상태 체크 관리
• 안건(Agenda)별 논의 내용 및 공식 결정사항 기록
➔
⚡ 4단계. Action Item 도출·할당
• 회의 결과로부터 실행 과제(Action Item) 즉시 도출
• 서브시스템 필터 연동 및 KPI 실시간 재집계
• 담당자, 완료목표일, 이행 상태 통합 트래킹
➔
📊 5단계. 주간보고 연동 & 출력
• 주간보고서 금주/차주 회의 일정 자동 편성
• Word (.docx) 5대 목차 + 6. 회의일정 통합 출력
• Excel (.xlsx) 제목 짤림 없는 셀 병합 출력

8. RBAC 권한 제어 & 보안 모델 (Security & Governance)

역할(Role) 부여 권한 범위 보안 통제 및 접근 제약
SYS_ADMIN 전체 시스템 마스터 권한 시스템 설정(tab-config), 비밀번호 변경, SDLC 마스터 커스터마이징, 아키텍처 정의서 조회, 전체 데이터 초기화 및 복원.
PM 프로젝트 공정 관리 권한 WBS 공정표 등록/수정, 산출물 검수 승인, 주간보고서 작성/저장, 회의 일정 등록 및 회의록 작성.
MEMBER 단위 과업 수행 권한 담당 서브시스템 과업 실적 입력, VOC 등록, Action Item 수행 상태 갱신, 공지/소통 피드 작성.

* XSS 방어: 사용자 입력이 DOM에 직접 바인딩되는 모든 렌더러에 escapeHtml 이스케이프 함수를 강제 적용했습니다.
