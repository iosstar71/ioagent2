# IOSTAR-PM Workgroup — 릴리즈 노트

## v1.3.3

- **샘플 프로젝트 추가 통일**: 두 판 모두 프로젝트 화면의 [🧪 샘플 프로젝트 추가]가 샘플을 **새 프로젝트**로 만듦 (Workgroup 은 서버에, 같은 멤버 ID 가 있으면 참여 정보만 붙임). Workgroup 의 [제조 샘플 복원](지금 프로젝트를 덮어씀)은 없앰
- **샘플 자료는 한 곳**: `static/js/core/sample-snapshot.js` 만 남기고, 코드 속 예전 샘플 값(Workgroup 기본 프로젝트 이름 · 예시 회의), 샘플 엑셀 · 샘플 생성 도구, 예전 DB 파일을 지움 (Workgroup 시험용 엑셀은 `tools/tests/fixtures/`)
- **초기 관리자 2개**: 두 판 모두 admin · admin2 (처음 암호 1234). 예전 설치에 admin2 가 없으면 처음 열 때 한 번 추가
- **기본 프로젝트(Default)**: 목록에 [기본 · 삭제 불가] 표시와 설명 (멤버 계정 · 화면 설정을 보관하는 자리 — 업무 자료는 [데이터 초기화])
- **산출물 화면**: Standalone 에서 첨부 칸이 빈 칸으로 끼어 열이 밀리던 것 고침
- 바로가기 문구 "시스템 설정 > 데이터 관리" → "Admin > 데이터 관리" (메뉴 이름과 같게)

## v1.3.2

- **CSS 정리 계속**: 앞 규칙이 `!important` 로 정한 속성을 뒤에서 다시 정한(적용되지 않는) 선언을 지우고(`tools/css_dedupe.py`), 화면을 바꾸지 않는 `!important` 를 뺌. `!important` 458 → 376, style.css 2,947 → 2,851줄. 6개 테마 × 모든 화면 · 대화상자에서 모양이 같음을 확인
- **정리 도구**: `css_safety_net.js --prune-important` 가 이미 지우기로 한 것과 함께 지운 상태를 원래와 비교하고, 보이는 화면에서만 판정 (`--prune-unused`: 쓰이지 않는 선언)

## v1.3.1

- **중복 CSS 정리**: 같은 선택자를 뒤에서 다시 정해 적용될 일이 없는 선언 132개 · 규칙 38개를 지움 (`tools/css_dedupe.py`). `!important` 619 → 458, style.css 3,165 → 2,947줄. 6개 테마 × 모든 화면 · 대화상자에서 모양이 같음을 확인
- **프로그램이 만드는 화면 조각의 인라인 스타일**: 고정 값은 공통 클래스로 (452 → 243, 남은 것은 계산된 값). 화면 부채 검사가 JS 안의 인라인 스타일도 셈
- **오류 기록**: 멤버 정보 이관이 실패하면 조용히 넘기지 않고 콘솔에 남김

## v1.3.0

- **보고서 VOC 수 바로잡음**: 주간보고 출력 · 종합보고서(PPT)의 "미완료 VOC"에 삭제한 VOC 가 섞이던 것을 고침. 미완료 판정을 `Metrics.vocOpen` 한 곳으로 (My Work 와 같은 기준)
- **더 빠른 화면 갱신**: 자료를 고치면 지금 보는 화면만 다시 그리고 다른 화면은 열 때 그림 (`ScreenRender` 표 하나). 샘플 기준 갱신 시간 약 30% 단축
- **화면 꾸밈 정리**: 자주 쓰는 인라인 스타일을 공통 클래스로 (830 → 531). 6개 테마 × 모든 화면 · 대화상자에서 모양이 같은 것을 확인
- **큰 파일 나누기**: 엑셀(형식 · 업로드 · 회의록 워드)과 회의(일정 · 회의록 · Action Item · 다운로드)를 기능별 파일로
- **시험 도구**: 화면 비교 도구(`css_safety_net.js`)가 6개 테마 · 대화상자 · 고정 시계로 비교 (`--save` / `--check` / `--dump`)
- **덮어쓰기 정리**: 공통 코드의 오래된 복사본 21개 삭제(회의 주최자 · 요청자 기본값이 고정 이름이던 것 등 → 지금 멤버), 첨부 · 잠금 연결 11곳은 공통 코드로. 덮어쓰기 24 → 20개 파일, 121 → 83개 메서드
