## v1.4.0

- **VOC · 결함 개편** (메뉴 이름 "VOC · 결함")
  - 칸 두 개: **단계**(요건분석/설계 · 구현/단위테스트 · 통합테스트 · 안정화 — 접수일이 들어가는 Phase 로 자동, 고치면 유지) · **판정**(미판정 · 결함 · 개선 요청 · 설명 종결 · 이슈). 결함이면 **심각도**(치명 · 높음 · 보통 · 낮음)
  - Phase 일정 표에 "VOC 단계" 열 — 비우면 Phase 이름으로 추정, Phase 일정이 없으면 WBS 의 Phase 행 일정으로 판단
  - **추가 요구사항으로 등록**: 판정이 개선 요청인 VOC 의 상세 패널 버튼(큰 개선만). 요구사항 목록에 "추가" · 별도 ID(기본 `CR-서브시스템-번호`)로 만들고 VOC 는 "요구 반영". 작은 개선은 VOC 안에서 처리
  - 집계: 요구 반영은 VOC 모수 · 처리에 들고 미결 · 지연 · 체크할 일에서 빠짐. **테스트 결함** = 통합테스트 단계 + 판정 결함 (안정화는 VOC 현황에만)
  - 대시보드: 판정 현황, **테스트 결함 카드 + 소진 차트**(통합테스트 접수가 있을 때만), 서브시스템별 · 단계별 표. Phase 현황 · Summary · 체크할 일(판정 대기) · 주간보고 · 종합보고서(결함 장표)에 반영
  - 범위 협의 알림: 한 서브시스템의 VOC 처리 개선 요청이 설정 건수(기본 10) 이상이면 Summary 에 알림 (Admin > 프로젝트 > 판정 기준)
  - 예전 자료 자동 변환: 구분 VOC → 미판정, 버그 → 결함, 상태 "제외" → 완료(미판정이면 설명 종결)
- **요구사항 · VOC 목록**: 상태별 숫자 줄을 없앰(상태 버튼에 같은 숫자), 처리율 · 초기/추가만 오른쪽에. 요구사항 목록에 구분(초기/추가) 걸러 보기
- **ID 규칙**: 추가 요구사항(CR) 접두사를 ID 규칙 표에 추가, 다음 번호는 가장 큰 번호 + 1, [ID 다시 매기기] 때 연결(WBS · VOC · 요구사항) 함께 바꿈
- **기준선 비교**: Admin > 프로젝트 > [📐 기준선 확정] (다시 확정할 때 사유 필수, 비교 기준 최초 · 직전). Gantt 에 기준선 선, WBS 상세 패널 "+N일", Summary · 주간보고 · 종합보고서에 "기준선 대비 종료 예정 +N일 · 밀린 Task". 엑셀 WBS 에 기준선 열(내려받기만), 업로드 · 파일 Merge 때 기준선 유지
- **엑셀**: VOC 시트 단계 · 판정 · 심각도 · 종료일 · 연결 요구사항, 요구사항 시트 구분 · 출처 VOC · 추가 등록일 (예전 양식도 읽음)
- 내부: Workgroup 덮어쓰기 중 엑셀 열 이름 표 · 자료 Merge 목록을 공통으로 합침
