# IOSTAR-PM Workgroup — 릴리즈 노트

## v1.2.5

- **Standalone 과 한 코드**: 화면 코드를 Standalone 과 한 벌로 합침 — 지금까지 따로 맞추던 Standalone 의 개선이 모두 들어옴
- Standalone 1.1 ~ 1.2.5 의 화면 개선: 주간보고 [최신 데이터 가져오기], 단계 가중치 합계 100 이하, 서브시스템 가중치 표시, 용어 통일(종합), 프로젝트 설정 탭 정리(서브시스템 · 산출물 · 부가정보 2열), 공정 유형 · 일정 미지정 표시, SDLC 유형 고르기(서로 다른 유형 최대 4개), 화면 이름 줄 고정 보정, 맨 위 아이콘 정리, 영어 화면 정리
- 유지보수: 예전 자료 변환 한 곳(migrate.js), 계산 기준 한 곳(metrics.js), 쓰지 않는 코드 정리
- 버전 번호를 Standalone 과 같게 1.2.5 로 (이전 0.6.0 까지를 1.0 으로 봄)
