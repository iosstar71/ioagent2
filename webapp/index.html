🔄 저장소 초기화 옵션 선택

원하시는 초기화 방식을 선택하세요. JSON을 제외한 다른 항목만 지우는 옵션을 사용하면 JSON 설정·연결 또는 JSON 데이터를 안전하게 보존할 수 있습니다.

🧹 옵션 1. JSON(환경설정·실시간 동기화)을 제외한 다른 항목 모두 지우기 (빈 테이블 초기화)

로컬 JSON 파일 동기화 연결 및 프로젝트 기본 설정(기간·기준일·휴일·표준산출물·테마)은 유지하고, 아래 선택된 업무 데이터 항목만 빈 상태(0건)로 모두 지웁니다.

🗂️ 옵션 2. LocalStorage 내 JSON 데이터만 보존하고 기타 저장소 항목(비밀번호·캐시 등) 모두 삭제

브라우저 저장소의 프로젝트 JSON 데이터(WBS_ENTERPRISE_SYSTEM_DATA_V9)는 100% 보존하고, 비밀번호 해시(기본값 1234로 초기화) 및 기타 불필요한 저장소 항목만 모두 지웁니다.

🔄 옵션 3. 저장소 전체 완전 초기화 (초기 샘플 데이터로 복원)

브라우저 로컬 저장소의 모든 데이터를 삭제하고 시스템 최초 샘플 데이터 상태로 완전히 복원합니다.
