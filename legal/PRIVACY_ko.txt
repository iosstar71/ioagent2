IOSTAR-PM — 개인정보 처리 안내 (초안)
==========================================================================
※ 이 문서는 초안입니다. 운영 기관의 개인정보 처리방침에 맞게 [ ] 항목을 채우고 검토 후 게시하십시오.

1. 처리하는 개인정보 항목
   - 사용자 계정: 사번(로그인 ID), 성명, 부서, 권한 등급, 담당 서브시스템, 화면 언어
   - 비밀번호: 원문을 저장하지 않으며, 복원할 수 없는 해시값만 저장합니다.
     (DB 서버 모드: 사용자별 솔트를 적용한 PBKDF2-SHA256 / 로컬 저장소 모드: SHA-256)
   - 작업 기록: 데이터 저장 시 저장한 사용자(성명·사번)와 시각, 회의 참석자·작성자, 공지·소통·채팅 작성자
   - 서버 접속 기록(DB 서버 모드): 접속 IP 주소, 요청 시각, 요청 경로, 로그인 성공·실패 기록
     (logs 폴더에 날짜별 파일로 저장되는 경우)

2. 처리 목적
   프로젝트 일정·산출물·보고 관리 업무 수행, 사용자 인증과 권한 관리, 보안 사고 확인

3. 저장 위치와 외부 전송
   - DB 서버 모드: 운영 기관 서버의 data 폴더(SQLite DB)와 logs 폴더
   - 로컬 저장소 모드: 각 PC 웹 브라우저의 저장소(LocalStorage)
   - 본 소프트웨어는 위 저장 위치 밖(인터넷, 제작사 등)으로 정보를 전송하지 않습니다.

4. 보유 기간과 파기
   - 사용자 계정: 관리자가 [기준정보 > 사용자 정보]에서 삭제할 때까지 [또는 퇴직·프로젝트 종료 후 n개월]
   - 서버 접속 기록: [n개월] 보관 후 logs 폴더의 해당 파일 삭제
   - 프로젝트 데이터: 프로젝트 종료 후 [n년] 보관, 이후 [프로젝트 관리 > 삭제] 또는 백업 파일 파기

5. 정보주체의 권리
   사용자는 본인 정보의 열람·정정(성명·부서·언어·비밀번호)을 요청할 수 있으며,
   삭제는 관리자에게 요청합니다. 문의: [개인정보 보호 담당자 / 부서 / 연락처]

6. 안전성 확보 조치
   로그인 인증 필수, 권한별 접근 제한, 비밀번호 해시 저장, 로그인 5회 실패 시 일시 차단,
   초기 비밀번호 사용 시 변경 강제, HTTPS(TLS 1.2 이상) 지원, 콘텐츠 보안 정책(CSP) 적용,
   서버·DB 파일 직접 다운로드 차단
